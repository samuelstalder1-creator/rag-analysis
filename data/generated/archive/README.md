# Historical datasets

- `base-1520/`: older paired correct/false corpora, including manual supplements.
- `qwen35-2b-all/`: the older full-corpus Qwen3.5-2B correct paraphrases.

Historical experiment configs are under `configs/archive/`; completed results are
under `results/archive/`. Dataset contents have not been rewritten. Directory
relocations are recorded in `data/generated/relocations.json`.
